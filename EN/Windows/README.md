# AI Context Bootstrap — Windows

This English package is self-contained for Windows. It configures Codex, Cursor, and Antigravity MCP; builds a local Graphify code graph; and prepares Codex Cloud scripts.

## Install

Drag the project folder onto `INSTALL.bat`, or double-click and enter its full path. Choose **Minimal** for the smallest MCP tool catalog. **Balanced** and **Full** are available when you need additional tools.

## Verify

Drag the project folder onto `CHECK_STATUS.bat`. Refresh the MCP list or restart your editor afterward.

Read the [complete guide](GUIDE.md), use the [agent prompt](AGENT_PROMPT.md) if you cannot run the installer, and inspect [setup-ai-context.ps1](setup-ai-context.ps1) before use. [Türkçe](../../TR/Windows/README.md).
