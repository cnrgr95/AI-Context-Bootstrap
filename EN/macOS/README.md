# AI Context Bootstrap — macOS

This English package is self-contained for macOS. It configures Codex, Cursor, and Antigravity MCP; builds a local Graphify code graph; and prepares Codex Cloud scripts.

## Install

Run `bash INSTALL.sh /absolute/path/to/project` from this folder. Choose **Minimal** for the smallest MCP tool catalog. **Balanced** and **Full** are available when you need additional tools.

## Verify

Run `bash CHECK_STATUS.sh /absolute/path/to/project`. Refresh the MCP list or restart your editor afterward.

Read the [complete guide](GUIDE.md), use the [agent prompt](AGENT_PROMPT.md) if you cannot run the installer, and inspect [setup-ai-context.sh](setup-ai-context.sh) before use. [Türkçe](../../TR/macOS/README.md).
