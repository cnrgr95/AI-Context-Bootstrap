# AI Context Bootstrap — Windows

Bu Türkçe paket Windows için bağımsızdır. Codex, Cursor ve Antigravity MCP bağlantılarını kurar, yerel Graphify kod grafı oluşturur ve Codex Cloud betiklerini hazırlar.

## Kurulum

Proje klasörünü `INSTALL.bat` üzerine sürükleyin veya çift tıklayıp tam yolunu girin. En küçük MCP araç kataloğu için **Minimal** seçin. Daha fazla araç gerektiğinde **Balanced** veya **Full** kullanabilirsiniz.

## Doğrulama

Proje klasörünü `CHECK_STATUS.bat` üzerine sürükleyin. Ardından editörünüzde MCP listesini yenileyin veya editörü yeniden başlatın.

[Ayrıntılı kılavuzu](GUIDE.md) okuyun; kurucuyu çalıştıramıyorsanız [ajan promptunu](AGENT_PROMPT.md) kullanın. Çalıştırmadan önce [setup-ai-context.ps1](setup-ai-context.ps1) dosyasını inceleyebilirsiniz. [English](../../EN/Windows/README.md).
