# Güvenlik politikası

Güvenlik açıklarını herkese açık bir issue yerine GitHub Security Advisories üzerinden özel olarak bildirin. Kimlik bilgilerini veya özel kaynak kodu paylaşmayın.

Kurucu seçilen projedeki ayarları günceller ve paket yöneticisi komutları çalıştırır. Çalıştırmadan önce betikleri inceleyin. Gizli bilgiler için ignore dosyalarına güvenlik sınırı olarak güvenmeyin; erişim izinleri ve gizli bilgi yöneticileri kullanın.

Codex Cloud, Graphify'ı ortamın kurulum aşamasında yükler. Görev sırasında internet erişimini yalnızca gerektiğinde açın; gerekiyorsa etki alanı ve HTTP yöntemi izinlerini dar tutun.

Güvenlik güncellemeleri en son sürüm için geçerlidir.
