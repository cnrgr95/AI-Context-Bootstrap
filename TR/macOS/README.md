# AI Context Bootstrap — macOS

Bu Türkçe paket macOS için bağımsızdır. Codex, Cursor ve Antigravity MCP bağlantılarını kurar, yerel Graphify kod grafı oluşturur ve Codex Cloud betiklerini hazırlar.

## Kurulum

Bu klasörde `bash INSTALL.sh /projenin/tam/yolu` çalıştırın. En küçük MCP araç kataloğu için **Minimal** seçin. Daha fazla araç gerektiğinde **Balanced** veya **Full** kullanabilirsiniz.

## Doğrulama

`bash CHECK_STATUS.sh /projenin/tam/yolu` çalıştırın. Ardından editörünüzde MCP listesini yenileyin veya editörü yeniden başlatın.

[Ayrıntılı kılavuzu](GUIDE.md) okuyun; kurucuyu çalıştıramıyorsanız [ajan promptunu](AGENT_PROMPT.md) kullanın. Çalıştırmadan önce [setup-ai-context.sh](setup-ai-context.sh) dosyasını inceleyebilirsiniz. [English](../../EN/macOS/README.md).
