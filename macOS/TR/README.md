# AI Context Bootstrap — macOS (Türkçe)

Depo kökünden `bash macOS/TR/INSTALL.sh /proje/yolu` çalıştırın. En küçük MCP araç kataloğu için Minimal profilini seçin. Kurucu, onarım veya profil değişimi için yeniden çalıştırılabilir.

`bash macOS/TR/CHECK_STATUS.sh /proje/yolu` çalıştırın. Kurulumdan sonra Codex, Cursor ve Antigravity uygulamalarında MCP listesini yenileyin veya uygulamaları yeniden başlatın.

Gereksinimler, Codex Cloud kurulumu, sorun giderme ve gelişmiş seçenekler için [Türkçe kılavuzu](../../TR/GUIDE.md) okuyun. [English](../EN/README.md).
