# AI Context Bootstrap — macOS (English)

Run `bash macOS/EN/INSTALL.sh /path/to/project` from the repository root. Choose Minimal for the smallest MCP tool catalog. The installer can be run again to repair or change the profile.

Run `bash macOS/EN/CHECK_STATUS.sh /path/to/project`. Refresh MCP or restart Codex, Cursor, and Antigravity after installation.

For prerequisites, Codex Cloud setup, troubleshooting, and advanced options, read the [English guide](../../EN/GUIDE.md). [Türkçe](../TR/README.md).
