# AI Context Bootstrap — Windows (English)

Drag your project folder onto `INSTALL.bat`, or double-click it and enter the project path. Choose Minimal for the smallest MCP tool catalog. The installer can be run again to repair or change the profile.

Drag the project folder onto `CHECK_STATUS.bat`. Refresh MCP or restart Codex, Cursor, and Antigravity after installation.
