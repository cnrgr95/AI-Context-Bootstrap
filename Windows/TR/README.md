# AI Context Bootstrap — Windows (Türkçe)

Proje klasörünü `INSTALL.bat` üzerine sürükleyin veya dosyaya çift tıklayıp proje yolunu girin. En küçük MCP araç kataloğu için Minimal profilini seçin. Kurucu, onarım veya profil değişimi için yeniden çalıştırılabilir.

Proje klasörünü `CHECK_STATUS.bat` üzerine sürükleyin. Kurulumdan sonra Codex, Cursor ve Antigravity uygulamalarında MCP listesini yenileyin veya uygulamaları yeniden başlatın.

Gereksinimler, Codex Cloud kurulumu, sorun giderme ve gelişmiş seçenekler için [Türkçe kılavuzu](../../TR/GUIDE.md) okuyun. [English](../EN/README.md).
